# SH | Personāls

Lietotne darbu vadītājiem: jauna darbinieka pieņemšana darbā un atvaļinājumu pieteikšana ar kalendāru.
Personāla vadītāja par katru pieteikumu saņem e-pastu, admins apstiprina pieteikumus.
Lietotni var pievienot telefona sākuma ekrānam.

Dati un loģika atrodas Google Apps Script / Google Sheets (`apps-script/Code.gs`) — šī lapa ir lietotnes saskarne.
Iestatīšana — `IESTATISANA.md`.
